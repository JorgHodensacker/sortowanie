# Sortowanie w Go

Projekt demonstracyjny sortowania w języku Go.

## Struktura katalogów
```sh
├── cmd
│   └── main.go
├── pkg
│   ├── utils.go
│   ├── sort_bubble.go
│   ├── sort_insert.go
│   └── sort_merge.go
├── go.mod
└── README.md
```


## Uruchomienie

Aby uruchomić program sortujący, użyj poniższej komendy, podając odpowiedni argument określający typ sortowania.

```sh
go run cmd/main.go <argument>
```
```sh
<argument> :
bubble - sortowanie typu bubble
insert - sortowanie typu insertion
merge - sortowanie typu merge
```
